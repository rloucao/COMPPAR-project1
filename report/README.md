# Report

Put the course LaTeX template here once it is released (the brief refers to a
`report/` folder template). Limits: 4 pages + 1 extra page.

Required sections: Introduction, Pipeline, Profiling and Baseline,
Optimisation Study (bottleneck / hypothesis / change / before-after per
optimisation + summary table), Analysis (scale + cluster size, at least one
chart), Discussion. Extra page: bibliography, acknowledgements (AI use),
individual contributions, comments.

Figures and tables should be generated from the JSON files in `../results/`.
